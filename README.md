# 한글 모아모아 도우미

메이플스토리 "한글 모아모아" 미니게임 화면을 읽어서, 이번에 받은 조각 3개를 **어떤 순서로, 어느 방향으로, 어디에** 놓으면 좋을지 알려주는 웹페이지입니다.

## 실행

1. `index.html`을 더블클릭해서 **크롬 또는 엣지**로 엽니다. 서버나 설치는 필요 없습니다.
2. 메이플스토리를 **창 모드**로 켜고 한글 모아모아 창을 엽니다.
3. **화면 공유 시작**을 누르고, 공유할 대상으로 메이플스토리 창이나 전체 화면을 고릅니다.
4. 게임판이 인식되면 왼쪽에는 놓을 위치가, 오른쪽에는 순서와 회전·반전 횟수가 나옵니다. 조각을 하나 놓을 때마다 다음 단계로 자동으로 넘어갑니다.

화면 공유를 쓰고 싶지 않으면 `Win`+`Shift`+`S`로 게임 창을 캡처한 뒤, 이 페이지에서 `Ctrl`+`V`로 붙여넣어도 됩니다. 이미지 파일을 끌어다 놓아도 됩니다.

## 안전성

- 게임 프로그램에 접근하거나, 키보드·마우스 입력을 보내거나, 메모리를 읽지 않습니다.
- 브라우저의 표준 화면 공유 기능(`getDisplayMedia`, 디스코드 웹 화면 공유와 같은 WebRTC 기능)으로 받은 영상만 읽습니다.
- 영상은 이 PC의 브라우저 안에서만 처리하며 외부로 보내지 않습니다. 인터넷은 글꼴을 받을 때만 씁니다.
- 공식 가이드에는 "비정상적인 방법을 통해 이벤트에 참여한 경우 이용이 제한될 수 있다"는 문구가 있습니다. 이 도구는 조작을 대신하지 않고 화면을 보며 조언만 하지만, 사용 여부는 직접 판단해 주세요.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 실시간 화면 · 추천 위치 | 공유 중인 실제 게임 화면 위에 이번에 놓을 칸(번호), 지워질 줄(흰 띠), 다음 단계(점선), 써야 할 조각 슬롯(색 테두리)이 표시됩니다. 위쪽 띠에 "몇 단계 · 몇 번째 조각 · 회전 몇 번"이 나옵니다. |
| 작은 창으로 띄우기 | 실시간 화면만 항상 위에 떠 있는 작은 창으로 꺼냅니다. 게임 옆에 두고 보면 편합니다(크롬/엣지). |
| 추천 배치도 | 게임판을 다시 그린 그림입니다. 단계를 눌러보거나 화살표 키 ←/→로 미리 볼 수 있습니다. |
| 추천 순서 | 몇 번째 조각을 몇 번 회전·반전해서 놓을지, 얻는 점수와 지워지는 줄 수를 보여줍니다. 게임 속 조각이 이미 목표 방향이면 "✓ 방향 그대로"로 바뀝니다. |
| 조언 | 점 찍기를 쓰면 더 좋은 경우, 조각을 놓을 자리가 없어서 바꿔 뽑기가 필요한 경우, 능력 아이템을 얻는 경우를 알려줍니다. |
| 직접 수정 | 인식이 틀렸을 때 칸을 눌러 블럭을 넣거나 빼고, 조각을 직접 고를 수 있습니다. |

## 추천 방식

- 점수 규칙은 공식 가이드를 따릅니다. 배치 점수는 조각의 칸 수이고, 가로줄을 동시에 지우면 1/2/3/4/5줄에 300/1,200/2,700/4,800/7,500점(300×n²)입니다. 능력을 얻으면 50점입니다.
- 3개 조각의 모든 순서, 회전·반전 방향, 위치 조합을 빔 탐색으로 계산합니다. 1회 계산에 0.1~0.4초 걸립니다.
- 배치 결과는 다음 기준으로 평가합니다.
  - **생존**: 19종 조각이 각각 놓일 자리가 남는지, 큰 조각(3×3, 3×4, 1×5)이 들어갈 빈 공간이 있는지, 고립된 빈칸이 없는지
  - **다중 제거 잠재력**: 다음 조각 하나로 몇 줄을 한꺼번에 지울 수 있는지
- 평가 가중치는 무작위 조각으로 자동 플레이하는 시뮬레이션으로 맞췄습니다. 튜닝에 쓰지 않은 48판으로 검증했을 때 평균 82,572점, 평균 118턴 생존이었습니다(초기 가중치는 35,738점, 59턴). 아이템 없이, 19종이 같은 확률로 나온다고 가정한 결과입니다.
- "오래 버티기 우선"이나 "다중 제거 우선"으로 바꾼 설정도 시험했지만 평균 점수와 생존 턴이 모두 낮아서 넣지 않았습니다.
- **놓는 순서**: 순서를 바꿔도 최종 판과 점수가 같으면, 기존 블럭이나 벽에 맞닿는 위치에 놓는 조각을 먼저 안내합니다. 허공에 뜬 위치는 다른 조각이 놓인 뒤로 미뤄서 위치를 착각하지 않게 합니다. 줄이 지워져야 다음 조각이 들어가는 경우처럼 순서가 결과를 바꾸면 원래 순서를 지킵니다.
- 아이템(점 찍기, 바꿔 뽑기)은 보너스로만 계산합니다. 블럭 위에 겹친 아이템 칸은 블럭으로 읽어 그 칸에는 놓지 않습니다. 능력이 가득 차면(7/7) 판의 아이템이 회색으로 바뀌는데, 이때는 지워도 얻을 수 없어서 점수 계산에서 뺍니다. 아이템 때문에 판을 망치는 배치는 고르지 않습니다.
- 블럭 19종은 `99. 제공자료/블럭의 종류.png`를 기준으로 합니다. 게임 속 'ㅋ 6칸'은 ㅠ를 회전·반전한 모양과 같습니다. 목록에 없는 모양이 나와도 화면에서 읽은 모양 그대로 계산합니다.

## 설정

- **[회전] 버튼 방향**: 게임에서 회전 버튼을 한 번 누르면 자동으로 감지해서 맞춥니다.
- **보유 능력**: 버튼이 회색(0개)인지는 자동으로 인식합니다. 개수는 직접 맞춰 주세요.

## 문제 해결

- **게임판을 못 찾아요**: 한글 모아모아 창이 다른 창에 가려지지 않았는지 확인하세요. 공유 화면이 검게 나오면 게임을 창 모드로 바꾸거나 [전체 화면]을 공유해 보세요.
- **전체 화면을 공유해도 되나요**: 됩니다. 이 페이지나 작은 창에 보이는 게임 화면 복사본에는 초록 표식 테두리가 있어서, 인식기가 복사본을 건너뛰고 실제 게임 창을 찾습니다. 다만 메이플스토리 **창만** 공유하는 쪽이 더 가볍고 확실합니다.
- **웨일에서 작은 창이 "웹페이지를 열 수 없어요"로 떠요**: 웨일은 크롬식 작은 창(문서형)을 제대로 띄우지 못해서, 웨일에서는 영상형 작은 창(팝업 플레이어)으로 띄웁니다. 안내 글자는 화면 위에 그려져 있어 그대로 보입니다.
- **컴퓨터가 느려지지 않나요**: 페이지는 게임판 주변만 잘라 0.45초마다 읽습니다. 브라우저를 최소화하거나 다른 탭을 보면(작은 창이 없을 때) 분석을 쉬고, 게임판이 5분 동안 안 보이면 화면 공유를 스스로 끕니다. 페이지를 닫으면 화면 공유도 함께 끕니다. 웹페이지는 키보드 입력에 끼어들 수 없으므로, 브라우저를 닫은 뒤에도 키 입력이 느리다면 작업 관리자에서 브라우저 프로세스가 남아 있는지 확인해 주세요.
- **조각을 드래그하는 동안 멈춰요**: 정상입니다. 드래그 중에는 줄 제거 미리보기가 칸을 가리므로, 게임판 위치와 추천 표시는 유지한 채("조각을 놓는 중") 화면이 안정될 때까지 기다립니다.
- **인식이 틀렸어요**: [직접 수정]으로 고친 뒤, 가능하면 그 순간의 스크린샷을 보관해 주세요. 인식 기준을 보정할 때 씁니다.
