사용 방법

  1. 메이플스토리를 창 모드로 켜고 한글 모아모아 창을 엽니다.
  2. 화면 공유 시작 → 공유할 창(메이플스토리) 또는 전체 화면을 고릅니다. 디스코드 웹 화면 공유와 같은 브라우저 표준 기능이며, 영상은 이 PC 밖으로 나가지 않습니다.
  3. 게임판이 인식되면 왼쪽에 놓을 위치, 오른쪽에 순서·회전 횟수가 나옵니다. 조각을 놓을 때마다 자동으로 다음 단계로 넘어갑니다.
  4. 화면 공유가 어렵다면 Win+Shift+S로 게임 창을 캡처한 뒤 이 페이지에서 Ctrl+V 해도 됩니다.

이 도구는 화면을 보기만 하고 게임 프로그램에 접근하거나 키보드·마우스 입력을 보내지 않습니다. 실제 조작은 직접 하셔야 합니다.
